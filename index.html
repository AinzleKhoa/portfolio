AnSite SafetyOps — AI Vision Safety Platform for Manufacturing SMEs

Lead Developer | Capstone Project → Startup | May 2026 – Present

NestJS, React 19, PostgreSQL, Socket.IO, Python, YOLO, MediaMTX

Inspired by my OJT work on VMS at Rikkeisoft.

  • Built a hybrid edge–cloud platform that turns existing factory CCTV into real-time safety alerts with stored evidence (PPE, restricted zones, falls, smoke, forklift–pedestrian proximity); validated through on-site surveys at 4 manufacturing companies.
  • Designed a resource-isolated architecture: a compute-bound Python edge agent on the factory LAN (RTSP, YOLO/VLM inference) and an I/O-bound NestJS API as the single database owner, linked by versioned alert, device-auth and live-view contracts.
  • Implemented per-device activation with authenticated HTTP/WebSocket channels and live camera viewing through a MediaMTX WebRTC/WHEP gateway relayed by the cloud.
  • Deployed to a VPS behind Caddy with a Cloudflare Pages frontend; enforced quality with GitHub Actions CI, 1,400+ edge tests, 69 cloud test suites, and backup/restore runbooks (RPO 6h, RTO 4h).

Backend Developer | Personal Project | Mar 2025 – Jun 2025

ASP.NET Core 8, EF Core, SQL Server, Ocelot, SignalR, Docker Compose
