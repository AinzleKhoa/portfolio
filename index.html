Capstone Project

AnSite: Camera-Based Safety Platform for Factories

Backend Developer | Capstone Project | NestJS, PostgreSQL, Socket.IO, Docker, Python

May 2026 - Present

  • Split the system by workload because raw video is bandwidth-heavy: a Python edge agent on the factory LAN handles camera streams and YOLO/VLM detection, while a NestJS cloud API centralizes database access, keeping AI processing isolated from the dashboard.
  • Fixed a lock-scope bug in the camera worker: the lock was held across slow frame processing and uploads, blocking live config updates for about 71 s; narrowing the critical section brought updates to 191-361 ms, with a regression test.
  • Implemented the NestJS alert ingestion API with idempotent writes (a retry with the same event ID and body returns the existing alert instead of creating a duplicate), composite PostgreSQL indexes for organization-scoped queries, and real-time updates through Socket.IO rooms.
  • Implemented per-device activation and SHA-256-hashed device credentials with constant-time comparison.
  • Deployed the NestJS API to a Linux VPS with Docker Compose and Caddy, with GitHub Actions CI for API, web and edge and a migration replay gate on a fresh PostgreSQL database.
  • Documented and enforced an AI-assisted delivery workflow: versioned AGENTS.md rules, plan-first changes with per-phase acceptance criteria, planner/executor separation, and an independent diff/CI audit before merge.

Experience

Software Engineer Intern (OJT)

Rikkeisoft | Ho Chi Minh City | VMS (Visitor & Manpower Management System)

Sep 2025 - Jan 2026

  • Implemented cache-stampede protection in a shared Redis caching package adopted by 4 NestJS services: a token-checked distributed lock lets only one request rebuild an expired entry while the rest back off with jitter, instead of a local lock that would not coordinate across service instances.
  • Implemented version-based cache invalidation (one Redis counter per entity, hashed query keys), so a write makes the entity's older cache keys unreachable, instead of scanning and deleting every query variant; traced and fixed a bug where one write bumped the version several times and invalidated cached entries too often.
